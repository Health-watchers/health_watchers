▶ Helm management:
  # Get current values
  helm get values {{ .Release.Name }} -n {{ .Values.global.namespace }}

  # Upgrade with a new image tag
  helm upgrade {{ .Release.Name }} ./helm/health-watchers \
    -f helm/health-watchers/values.yaml \
    -f helm/health-watchers/values-production.yaml \
    --set api.image.tag=<NEW_TAG> \
    --set web.image.tag=<NEW_TAG> \
    --set stellarService.image.tag=<NEW_TAG>

  # Rollback to previous release
  helm rollback {{ .Release.Name }} -n {{ .Values.global.namespace }}

  # View release history
  helm history {{ .Release.Name }} -n {{ .Values.global.namespace }}

⚠️  IMPORTANT: Secrets
  Ensure the following secrets are set (never commit real values):
    - secrets.mongoUri
    - secrets.jwtAccessTokenSecret
    - secrets.jwtRefreshTokenSecret
    - secrets.stellarSecretKey
    - secrets.fieldEncryptionKey

  Use --set or a sealed-secrets solution. For production, enable:
    secrets.useExternalSecrets: true
