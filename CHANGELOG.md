# Changelog

All notable changes to this project are documented in this file.

Dated version entries below are generated automatically by
[Changesets](https://github.com/changesets/changesets) through the release
workflow (`.github/workflows/release.yml`). Contributors describe their changes
in `.changeset/` files; when those changesets are merged, the release workflow
opens a "Version Packages" pull request and, once merged, publishes the new
versions and appends the corresponding entries here.

Do not edit this file by hand. To record a change, add a changeset instead.

> **API versioning and endpoint reference:** the API versioning policy,
> deprecation rules, and the endpoint reference have moved to
> [`docs/API_VERSIONING_GUIDE.md`](./docs/API_VERSIONING_GUIDE.md) and the
> OpenAPI specification. See that guide for details on `/api/v1/`, `/api/v2/`,
> and later versions.
