# Guide de l'utilisateur

Ces guides s'adressent aux **administrateurs de clinique et au personnel d'accueil**. Chaque guide décrit une tâche dans l'application web Health Watchers, étape par étape, sans connaissances techniques.

| Tâche | Guide | Qui |
|-------|-------|-----|
| Configurer une nouvelle clinique | [Intégration d'une clinique](/user-guide/onboarding-a-clinic) | Administrateur de clinique |
| Ajouter des médecins, infirmiers et personnel d'accueil | [Inviter du personnel](/user-guide/inviting-staff) | Administrateur de clinique |
| Configurer les alertes cliniques et les codes de diagnostic courants | [Règles d'aide à la décision et favoris CIM-10](/user-guide/cds-rules-and-icd10-favourites) | Administrateur, Médecin |
| Recevoir les paiements des patients | [Portefeuille Stellar et paiements](/user-guide/stellar-wallet-and-payments) | Administrateur de clinique |
| Suivre les performances de la clinique | [Rapports](/user-guide/running-reports) | Administrateur de clinique |
| Répondre à une demande de données d'un patient | [Demandes de données des patients](/user-guide/patient-data-requests) | Administrateur de clinique |

Les guides détaillés sont en cours de traduction ; en attendant, ils s'affichent en anglais. Voir le [plan de traduction](/user-guide/translations).
