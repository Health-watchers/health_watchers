# Guide Testing Checklist

Each user guide must be followed end to end by someone who has **never used Health Watchers**, on a test clinic seeded with demo data (never real patient data).

## Procedure

1. Give the tester only the guide and a test account with the role named in the guide.
2. Ask them to complete the task without help, thinking aloud.
3. Note every point where they hesitate, ask a question, or the screen does not match the guide.
4. Fix the guide (or file a bug for the app), then repeat with a new tester until the task is completed without help.
