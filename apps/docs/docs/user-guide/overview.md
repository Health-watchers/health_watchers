# User Guide

These guides are for **clinic administrators and front-desk staff**. Each guide walks through one task in the Health Watchers web app, step by step, with no technical knowledge required.

| Task | Guide | Who |
|------|-------|-----|
| Set up a new clinic | [Onboarding a clinic](./onboarding-a-clinic.md) | Clinic Admin |
| Add doctors, nurses and front-desk staff | [Inviting staff](./inviting-staff.md) | Clinic Admin |
| Configure clinical alerts and common diagnosis codes | [CDS rules and ICD-10 favourites](./cds-rules-and-icd10-favourites.md) | Clinic Admin, Doctor |
| Receive patient payments | [Stellar wallet and payments](./stellar-wallet-and-payments.md) | Clinic Admin |
| See how the clinic is performing | [Running reports](./running-reports.md) | Clinic Admin |
| Respond to a patient asking for their data | [Handling patient data requests](./patient-data-requests.md) | Clinic Admin |

Before you start, make sure you can sign in at your clinic's Health Watchers address. Sign in with the account your administrator created for you.

Each guide is validated with the [guide testing checklist](./guide-testing.md). French versions are planned. See the [translation plan](./translations.md).
