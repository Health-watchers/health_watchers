The 22 high-severity findings from `npm audit` must be individually reviewed. Common sources in a stack of this size include transitive dependencies of `express`, `mongoose`, `axios`, and `multer`. Run the following to see the full advisory list:


For each advisory:
1. Check if a fixed version is available (`npm audit fix --dry-run`).
2. If auto-fixable, include in the Tier 1 PR.
3. If not auto-fixable (breaking fix required), create a dedicated issue and link it to this audit report.
4. If the vulnerability is in a dev-only dependency, document the risk acceptance in the issue.
